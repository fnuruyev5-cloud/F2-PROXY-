# F2 PROXY V1.1 — Android layihəsi

Bu layihə qırmızı-qara vizual üzən menyu nümunəsidir. Free Fire fayllarını dəyişmir, oyun yaddaşına toxunmur və real proxy bağlantısı yaratmır.

## APK necə hazırlanır (telefonla)
1. ZIP-i GitHub-da yeni repository-yə yüklə və faylları kök qovluğa çıxar.
2. Repository-də **Actions** bölməsini aç.
3. **Build F2 PROXY APK** workflow-nu seç və **Run workflow** bas.
4. Bitdikdən sonra workflow nəticəsində **F2-PROXY-V1.1-APK** artifact-ni yüklə.
5. ZIP artifact-ni aç; içində `app-debug.apk` olacaq.

## Telefon icazəsi
İlk dəfə START basanda Android-in “Display over other apps / Digər tətbiqlərin üzərində göstər” icazəsini aktivləşdir. Sonra tətbiqə qayıt və START bas.

## Qeyd
- START quraşdırılmış Free Fire və ya Free Fire MAX-ı açmağa çalışır.
- Ekrandakı F2 düyməsi sürüşdürülə bilər; toxunanda demo panel açılıb-bağlanır.
- IP/port/status mətnləri real şəbəkə məlumatı deyil, yalnız maketdir.
